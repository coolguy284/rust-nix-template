# rust-nix-template

This repo provides a template nix flake configuration to compile a rust project for both linux and windows in a theoretically convenient and immutable manner.

## Usage

See `scripts` folder for usage scripts. To create a new project, copy the following items:
- `.vscode`
- `scripts`
- `src`
- `.gitignore`
- `Cargo.lock`
- `Cargo.toml`
- `flake.lock`
- `flake.nix`
- `rustfmt.toml`
